Apple M4 Pro, macOS 27.0.1, Darwin arm64, 비교 모드마다 루프백 HTTP/1.1 요청.
로컬 Temurin 25.0.4.1, Kotlin/JVM 2.3.21, kotlinx-coroutines-core-jvm 1.10.2.
가상 스레드 이벤트의 JDK 21 대조군은 Microsoft OpenJDK 21.0.12.1이다.

가상 스레드와 JFR
JDK 25 javac --release 21로 만든 같은 class를 두 JDK에 건넨다.
JDK 21/25의 경로는 설치한 JDK에 맞춰 지정한다. 빌드와 실행은 macOS ARM64에서 확인했다.
Linux에서는 -dynamiclib 대신 -shared -fPIC, include/darwin 대신 include/linux,
libpinprobe.dylib 대신 libpinprobe.so로 빌드할 수 있다.

javac --release 21 PinProbe.java
jdk21=$(/usr/libexec/java_home -v 21)
jdk25=$(/usr/libexec/java_home -v 25)
cc -dynamiclib -I"$jdk25/include" -I"$jdk25/include/darwin" pin_callback.c -o libpinprobe.dylib
for jdk in "$jdk21" "$jdk25"; do
  for mode in monitor native; do
    "$jdk/bin/java" --enable-native-access=ALL-UNNAMED -Djava.library.path=. PinProbe "$mode"
  done
done

코루틴
실측은 Kotlin 2.3.21의 K2JVMCompiler와 같은 버전의 stdlib을 사용했다.
같은 버전의 kotlinc/kotlin CLI로 재현할 때의 명령이다.

curl -fsSL --max-time 60 -o coroutines.jar https://repo.maven.apache.org/maven2/org/jetbrains/kotlinx/kotlinx-coroutines-core-jvm/1.10.2/kotlinx-coroutines-core-jvm-1.10.2.jar
kotlinc -jvm-target 21 -classpath coroutines.jar CoroutineLab.kt -d coroutine-lab.jar
kotlin -classpath coroutine-lab.jar:coroutines.jar CoroutineLabKt
