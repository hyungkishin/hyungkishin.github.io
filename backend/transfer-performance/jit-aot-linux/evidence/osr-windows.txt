Temurin 25.0.5+8, Linux ARM64 (Docker), G1, 힙 48MiB. 호스트 Temurin javac 25.0.4.1.
컴파일 대상으로 longLoop/quote만 허용했다. 이 설정과 JFR은 평상시 기동시간 비교에 쓰지 않는다.
실행 ID와 시각, 계수, 정지 시간은 실행마다 달라진다.

재현 (HotPathProbe.java와 window-report.py를 빈 폴더에 두고 실행)
javac --release 25 -g HotPathProbe.java
javap -c -p HotPathProbe
image=eclipse-temurin@sha256:ecdc0adb37bde1a281c4d245a3cd535004b1fc8322d560f5b09463b248c81df0
jvmrun() { docker run --rm --network=none --platform linux/arm64 -v "$PWD:/lab" -w /lab "$image" "$@"; }
jvmrun java -Xms48m -Xmx48m -XX:+UseG1GC -XX:+UnlockDiagnosticVMOptions -XX:+LogCompilation \
  -XX:LogFile=hot.xml -XX:+PrintCompilation -XX:CompileCommand=compileonly,HotPathProbe::longLoop \
  -XX:CompileCommand=compileonly,HotPathProbe::quote HotPathProbe > hot.out
jvmrun jfr print --json --events 'lab.Window,jdk.Compilation,jdk.Deoptimization,jdk.GCPhasePause' hot.jfr > events.json
python3 window-report.py events.json
mkdir -p interpreted
docker run --rm --network=none --platform linux/arm64 -v "$PWD:/lab" -w /lab/interpreted "$image" \
  java -Xint -Xms48m -Xmx48m -cp /lab HotPathProbe
