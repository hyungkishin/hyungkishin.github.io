Temurin 25.0.4.1+1, macOS arm64, G1, heap 64 MiB, region 1 MiB.
각 길이는 새 JVM에서 실행했다. 아래는 할당 후 명시적 GC 한 번의 초기화 로그와 힙 요약이다.

javac HumongousProbe.java
for n in 500000 600000 1100000; do
  java -Xms64m -Xmx64m -XX:+UseG1GC -XX:G1HeapRegionSize=1m \
    -Xlog:gc+init=info,gc+heap=info HumongousProbe "$n"
done
